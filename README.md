# Haste Save HotLoader

# Description

[Workshop Mod](https://steamcommunity.com/sharedfiles/filedetails/?id=3474956207)

**Launch a specific Haste save file from the Main Menu**!  
The save is stored (temporarily) on save slot 4200. You can leave to the main menu and come back in your save as any other save file.  
However, **your hotloaded save file will be overwritten if you hotload an other save file**.  
The main goal of the mod is to facilitate speedrunning, and racing.
